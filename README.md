# Personal-portfolio-website
A modern personal developer portfolio website built using **HTML, CSS, and JavaScript** with an elegant **white, beige, and maroon** color palette.

## Features
- Responsive design for mobile, tablet, and desktop
- Sticky navigation bar
- Smooth scrolling
- Hero section
- About section
- Skills showcase
- Projects section
- Contact form
- Back-to-top button
- Clean and beginner-friendly code structure

## Design Theme
- White
- Beige
- Maroon

## Built With
- HTML5
- CSS3
- JavaScript (Vanilla JS)
